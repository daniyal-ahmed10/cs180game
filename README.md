# CS 180 Project - Ritmo

A 2D rhythm game where you hit notes in time with music, inspired by classic rhythm games such as 'Osu!' and 'Rhythm Doctor'. Ritmo will use Googles Mediapipe Library to add a unique playstyle, where users use their hands in sync to the music to interact with the game, rather than the classic keyboard inputs. Ac classic play style will be available as well, for users that prefer keyboard inputs.

## How to play

- **Keyboard levels:** Press **D, F, J, K** when notes reach the hit line.
- **Motion levels:** Match your hand into the target zone to the hand symbol shown on screen. Use blue notes for your left hand and red notes for your right.

## Built with
- Godot 4 (GDScript)
- Python, MediaPipe and OpenCV for hand tracking
- VS Code with the godot-tools extension
