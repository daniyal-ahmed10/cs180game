# CS 180 Project - Ritmo

A 2D rhythm game where you hit notes in time with music. Some levels use the keyboard, and others use hand tracking through your webcam.

## How to play

- **Keyboard levels:** Press **D, F, J, K** when notes reach the hit line.
- **Motion levels:** Move your hand into the target zone as the ring closes. Use blue notes for your left hand and red notes for your right.

## Built with

- Godot 4 (GDScript)
- Python, MediaPipe and OpenCV for hand tracking
- VS Code with the godot-tools extension
